# Security Policy

## Supported Version

Cabang utama `main` adalah versi yang aktif dipelihara.

## Reporting a Vulnerability

Laporkan celah keamanan melalui [GitHub Private Vulnerability Reporting](https://github.com/ruhy4t/rahayat-cms/security/advisories/new)
sebelum membuka issue publik. Jika fitur tersebut tidak tersedia, hubungi
maintainer melalui profil GitHub tanpa mempublikasikan detail celah. Sertakan:

- Ringkasan celah.
- Langkah reproduksi.
- Dampak yang mungkin terjadi.
- Saran perbaikan jika ada.

Jangan menyertakan data pribadi siswa, dokumen SPMB, credential, atau dump
database dalam laporan.

Maintainer akan mengonfirmasi penerimaan laporan, menilai dampak, dan
mengoordinasikan perbaikan serta pengungkapan sebelum detail dipublikasikan.
